## Confirmed findings

### ECR001 — Checked difficulty APIs still panic on unsupported caller windows/extreme heights

**P2 · public API correctness/error contract · SOURCE_CONFIRMED.** `src/difficulty.rs:246–275` advertises structured errors for caller misuse; codemap explicitly says never panics. `next_n_bits:328–334` and `verify_header_difficulty` reach this core through safe public APIs. Parent height+1 at270/272 overflows for u32::MAX. `calculate:109–114` divides by every adjacent elapsed timestamp without checking positivity: with≥3 supplied headers, an equal adjacent timestamp can coexist with first.timestamp<last.timestamp and reach BigUint division by zero. Reversed adjacent timestamps underflow in checked builds and wrap in unchecked builds; EIP37 classic subtraction at187 has the same unchecked relation. Window height intervals/ordering are not checked, unlike pinned Scala `calculate`'s interval require. `previous_heights_for_recalculation:64,69,74` and interpolation241 also use unchecked u32 arithmetic for raw extremes/large epochs.

The concrete precondition is **caller-built or locally inconsistent epoch context/config**, not a proved peer path. Ordinary SYNC selects sorted requested heights from the parent's branch and VALIDATION enforces monotonic direct-parent timestamps; trusted previously validated ancestors close duplicate/reversed-window inputs. No canonical-network crash, captured wrong accepted block or new runtime demonstration is claimed. Rust1.95 `is_multiple_of(0)` is explicitly nonpanicking: zero epoch can silently suppress retarget for nonzero parent; do not misdiagnose it as `%0` panic. Scala also throws on some malformed supplied inputs, so this finding is an API/error promise, not unique consensus arithmetic divergence.

Fix: either narrow and document authenticated-window/validated-config/Panics preconditions, or validate them at a checked constructor/Result boundary using checked height arithmetic and typed invalid-window/config errors. Preserve valid Scala rounding, normalization and early-chain fallback. Add meaningful public-boundary cases for duplicate/reversed timestamps, mismatched epoch spacing, zero/oversized epochs, u32 edges and typed missing context; prove ordinary canonical windows still match independent nBits. Existing empty/short/height-mismatch tests cover only three declared failures and miss these branches.
