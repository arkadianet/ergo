### API-012 — Global-range routes translate the wrong paging window

**P2 · reference/API window semantics · SOURCE_CONFIRMED.** `ergo-api/src/blockchain/range.rs:24–33/50–67` passes `[offset,offset+limit)` to numeric global-range methods and emits returned order. Pinned Scala6.0.5 BlockchainApiRoute187–194/340–347 reads the committed global counter, computes `base=counter-offset`, collects `base-limit+i` and **reverses** the IDs.
